# 开发规范

## 目录与命名

- 前端使用 Vue 单文件组件和 TypeScript。组件文件使用 `PascalCase`，页面组件以 `Page.vue` 结尾。`views/` 按业务组织，`components/` 存放可复用组件，`api/` 存放接口调用。
- 后端使用 Python 的 `snake_case` 命名模块和函数。`users` 负责用户与认证，`approvals` 负责申请单、审批和历史。接口层处理请求和响应，审批服务负责状态流转和事务。Python 缩进使用四个空格，前端缩进使用两个空格。

## API、迁移与配置

- API 路由、字段与状态码以 [OpenAPI 契约](../openapi.json) 为准。接口调整时同步更新契约。业务接口默认要求 JWT 认证，注册和登录添加后应显式允许匿名访问。
- 使用 Django Migration 管理数据结构变化。模型变更随迁移提交，评审时检查迁移操作与数据影响。数据库与 Django 密钥通过环境变量配置，仓库保留 `.env.example`。
- 依赖调整时同步更新 `frontend/package-lock.json` 或 `backend/uv.lock`。

## 提交与验证

- 从 `main` 建立任务分支，按可以独立说明的改动提交。评审说明包含改动目标、主要影响和验证结果。
- 修改权限、审批流转或数据库事务时，按 [Spec 验收条件](Spec.md#9-验收条件) 补充验证。回滚和并发场景使用 PostgreSQL 验证。
- AI 辅助生成的代码由提交者检查，核对需求、错误分支和数据变更，运行相关检查并记录结果。
